What this pipeline produces

Temporal crown tracking

Individual tree crowns detected on each date are linked across the full time series into persistent chains. A consensus polygon represents each tree's stable canopy footprint.

Per-crown phenology curves

For every tracked tree, the pipeline extracts vegetation fraction, GCC, Laplacian texture variance, and grayscale intensity at each survey date. A deciduousness score separates seasonal trees from evergreens.

Interactive visualization

A self-contained Leaflet viewer lets you pan, zoom, switch between survey dates, and click any crown to see its chain ID, phenophase label, and seasonal greenness timeline.

From drone imagery to phenology map

The processing pipeline runs five steps in sequence. Each step reads a shared configuration file and writes outputs the next step consumes.

0

Upload orthomosaics

Minimum 5 different orthomosaics of the same site are required for good results. Upload your georeferenced .tif files and enter the acquisition date for each one.

1

Crown detection

Runs a Detectree2 Mask R-CNN model on each orthomosaic to delineate tree crown polygons. The raster is tiled into overlapping windows for inference, then duplicates are merged by IoU.

2

Crown tracking

Aligns dates using high-confidence anchor crowns, then links each tree across the time series into a chain. A consensus polygon is derived from every chain.

3

Phenology analysis and classification

Extracts vegetation fraction, GCC, Laplacian texture, and grayscale mean for each crown at each date. Combines these into a deciduousness score that separates seasonal from evergreen trees. A gradient-boosting classifier then labels each crown-date pair as leaf-on, leaf-off, or transitioning.

4

Tiling and interactive viewer

Converts each orthomosaic into a Cloud-Optimized GeoTIFF and pre-renders XYZ tile pyramids. Then assembles a standalone Leaflet web map that combines the tiles, consensus crown layer, and classified phenology data. Click any crown to see its seasonal greenness curve.
