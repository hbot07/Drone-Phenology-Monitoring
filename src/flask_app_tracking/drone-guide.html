Drone flight guide

A step-by-step walkthrough for designing flight paths, uploading them to your drone, flying the survey, and building orthomosaics from the captured imagery. This guide uses Map Pilot Pro for flight planning and WebODM for orthomosaic generation.

Sections

  1. Create and export flight paths
  2. Upload the flight path to your drone
  3. Fly the survey mission
  4. Build the orthomosaic in WebODM

1. Create and export flight paths

Use Map Pilot Pro on your phone to draw the survey area, configure flight parameters, and export a KMZ file.

1

Install Map Pilot Pro

Install Map Pilot Pro from the Google Play Store or Apple App Store. It is free for basic flight planning and KMZ export.

2

Open the app and go to Settings

From the home screen, tap Settings to configure the app for KMZ export.

3

Enable "Export Simple KMZ" in Advanced Settings

Go to Advanced Settings and turn on Export Simple KMZ. Without this, flight paths can only be exported in the MME format, which is not recognized by other drone apps or GIS software.

Required. If this toggle is off, the export option in later steps will not produce a KMZ file.
4

Select an "Export Only" camera model

Go to Flight Camera, then Model, and select a camera that shows "(Export Only)" in the name. This is required to enable KMZ export.

5

Create a new mission

Go back to the home screen and tap New Mission. Dismiss any popup dialogs that appear.

6

Navigate to your survey area

The default viewport shows Lower Manhattan. Zoom out and navigate to your site. If your phone GPS is on and you are near the site, the map will center on your location automatically.

7

Set flight parameters

Configure the altitude, speed, and overlap. Tap Norm Mission, then Normal.

ParameterRecommended value
Altitude80 m (ideal for phenology)
Speed3 m/s (slow for sharp images)
Front overlap80%
Side overlap80%
GSD guidance. For class-specific overlap recommendations and ground sampling distance, see the WebODM image capture guide.
8

Minimize the top bar for better visibility

Tap the bar that shows "Export Only" to collapse it, giving you a larger view of the map while drawing the boundary.

9

Set the Home point

Long-press on the map to place the purple Home point dot. This is where the drone will return after completing the flight path.

10

Draw the survey boundary

Long-press to place orange Boundary dots around your survey area. Start with the initial three dots to roughly cover the area, then adjust the smaller orange midpoint dots to refine the boundary shape.

No undo. There is no undo or redo for boundary edits. If you make a mistake, delete the entire flight path using the trash icon at the top left and start over.
11

Save the mission optional

Tap the floppy disk icon at the top left, give the mission a name, and save it. This lets you reload the same flight path for repeated surveys at the same site.

12

Export as KMZ

Tap the drone/airplane icon at the top right, then tap Export. Click No on the Terrain Awareness popup (this feature requires a paid account). Give the flight path a name, tap Export, then OK.

The KMZ file will be saved to the Downloads folder on your phone.

13

Exit the mission editor

Tap the left-facing triangle to reveal the Exit icon, then tap it to return to the home screen.

+

Use boundary files as reference optional

If you have a shapefile or KML of your region of interest, you can import it to use as a visual guide while drawing the flight boundary.

Convert your shapefile to KMZ format using QGIS, then in Map Pilot Pro go to File Manager, tap Import, navigate to the file, and import it. Under Imported Overlay Files, turn on Show KML, then tap Sync so the boundary appears on the map. Create a new mission and draw the flight path using the imported boundary as a guide.

Multi-battery flights. If the boundary is large, the flight path will show white line segments (first battery) and grey segments (additional batteries required). The drone returns to the Home point when the first battery is depleted, and continues from where it left off after a battery swap.

2. Upload the flight path to your drone

For DJI drones with a remote controller (RC), the KMZ file needs to be placed in the correct directory on the RC's internal storage.

1

Connect the drone and open the DJI Fly app

In the RC or DJI Fly app, connect the drone and press Go Fly. Make sure the drone is placed outside for adequate satellite signal.

2

Open the map view

Tap the map at the bottom-left corner. Make sure your current position is shown on the map.

3

Create a dummy waypoint mission

Tap the waypoint icon on the left side and create a waypoint with at least 2 points. This creates the folder structure the DJI app expects.

4

Save the dummy waypoint

Tap the note/paper icon to the left of "Waypoint", select the waypoint, then press SAVE, then Save. Return to the home screen and press Save and Exit.

5

Connect the RC to your computer

Use USB to connect the remote controller to your desktop or laptop. Navigate to:

DJI RC 2 > Internal Shared Storage > Android > data > Dji.go.v5 > files > waypoint

Open the most recently created folder. It will contain the dummy waypoint's KMZ file.

6

Copy the KMZ filename

Copy the name of the KMZ file inside that folder (it will be a UUID like 90A8341C-CFE2-4E84-8681-B5B081E5C815.kmz).

7

Rename and replace

Rename your Map Pilot Pro KMZ file to match the copied UUID filename. Then copy it into the waypoint folder on the RC, replacing the original dummy file. Disconnect the RC from the computer.

8

Verify on the RC

Connect the RC to the drone. Navigate to the waypoint list using the note/paper icon. The Map Pilot Pro flight path should now appear in the saved waypoints.

3. Fly the survey mission

Execute the uploaded flight path using the DJI Fly app's waypoint mode. These steps apply to the DJI Mini 4 Pro and DJI Mini 5 Pro.

1

Connect and move to an open area

Power on the drone and RC. Ensure you are in an open area with clear line of sight and no overhead obstructions.

2

Select waypoint mode

In the DJI Fly app, select the waypoint flight mode icon.

3

Load the flight path

Tap the list button, then select the flight path you uploaded in Section 2. It will display the number of waypoints. Tap Next.

4

Verify settings and launch

All fields will be pre-filled from the Map Pilot Pro configuration (altitude, speed, overlap). Review the settings, then press Go to launch the survey flight.

Safety. Maintain visual line of sight with the drone at all times. Be prepared to take manual control using the RC sticks if the drone approaches obstacles.
5

Handle multi-battery flights

If the survey area requires multiple batteries (grey segments in the flight plan), the drone will return to the Home point when the first battery is depleted. Replace the battery and resume the mission from the waypoint list. The drone will continue from where it stopped.

6

Transfer images from the drone

After the flight is complete, connect the drone or remove the SD card and copy all captured images to your computer. Keep all images from a single flight in one folder.

4. Build the orthomosaic in WebODM

WebODM is a free, open-source tool that stitches drone photos into a georeferenced orthomosaic. The output is a GeoTIFF file ready for the phenology pipeline.

1

Install WebODM

Follow the official installation guide. WebODM runs on Linux, Windows (via WSL2), and macOS. Docker and Git are prerequisites.

WSL2 troubleshooting. If you have trouble installing WSL2 on Windows, see this installation guide with troubleshooting.
2

Allocate sufficient memory (Windows)

On Windows, open WSL Settings and increase the Memory Size allocation. For a machine with 32 GB RAM, set it to approximately 28,000 MB, leaving some memory for Windows itself. More RAM dramatically improves processing speed for large image sets.

3

Launch WebODM and create an account

Start WebODM from the command line, then open it in a browser at http://localhost:8000. Create an account on first launch.

4

Upload images

Click Select Images and GCP. Navigate to the folder containing all images from your flight, select them all, and click Open.

5

Configure processing options

Click Edit under Options and set the following parameters:

OptionRecommendation
Fast OrthophotoEnable (consistently produces fewer distortions)
skip-3dmodelEnable (saves significant time, no effect on orthomosaic quality)
max-concurrencyReduce if you experience memory issues
optimize-disk-spaceEnable if low on disk space (deletes intermediate files)
6

Start processing

Click Review, then Start Processing. Close other memory-heavy applications (QGIS, many browser tabs) before starting. Processing time depends on the number of images and available hardware.

7

Download the orthomosaic

Once processing completes, download the orthomosaic as a GeoTIFF (.tif) file from WebODM's interface. This file is what you upload to the Drone Phenology Monitoring dashboard as an orthomosaic.

Repeat for each survey date. You need at least 5 orthomosaics of the same site at different dates to run the phenology pipeline. Fly the same flight path each time to ensure consistent coverage.
