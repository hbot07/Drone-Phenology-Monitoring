Before you start

Make sure you have the following ready before creating a run. The pipeline expects all inputs to be consistent across survey dates.

Orthomosaics

You need at least 5 georeferenced orthomosaics of the same site, each from a different survey date. Fewer dates produce unreliable phenology curves — 5 is the practical minimum, and more is always better. Each file must be a GeoTIFF (.tif) with a valid CRS and spatial extent. Build your orthomosaics from drone imagery using a tool like OpenDroneMap (WebODM) or Pix4D before uploading here.

Consistent flight plan

All orthomosaics must cover the same geographical area. Fly the same planned flight path for every survey date using a tool like Map Pilot Pro. The pipeline aligns dates using detected crown anchors — if the spatial overlap between dates is too low, alignment will fail. Aim for nadir imagery at 3–5 cm/px ground sampling distance and 80% front and side overlap.

Survey dates

Dates must span a full seasonal cycle to capture leaf-on, leaf-off, and transitional phases. For deciduous trees in a temperate climate, this means surveys spread across at least one growing season — ideally covering winter (bare crowns), spring flush, summer canopy, and autumn senescence. The pipeline derives phenophase labels from the temporal signal, so surveys clustered within a single month will not produce meaningful results.

New to drone surveying? The Drone Flight Guide walks through designing a flight path in Map Pilot Pro, uploading it to a DJI drone, flying the mission, and building orthomosaics in WebODM. The Pipeline Walkthrough explains what each step does and what parameters to tune.
