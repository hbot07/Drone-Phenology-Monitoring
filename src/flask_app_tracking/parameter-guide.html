On this page

    You can leave everything at its default for a first run — the pipeline is calibrated for typical 5 cm/px drone surveys. Use this guide when a result looks wrong and you want to know which knob to turn.

    Running a survey, start to finish

    Five steps, in order, on one page.

    1
    Name the run

    Anything you recognise later — underscores instead of spaces.

    2
    Upload your orthomosaics

    Drop in all the .tif files for this survey — any filename is accepted. You need at least five dates for meaningful phenology.

    3
    Enter acquisition dates

    Each file needs a date (DD/MM/YYYY) — the pipeline uses these to sort the time series chronologically.

    4
    Leave settings at defaults

    The defaults work well for most sites. Expand a section only if you have a specific reason to change something.

    5
    Click Upload & start pipeline

    The seven steps run on the server in sequence. Progress updates live; you can close the tab and come back — the run continues.
