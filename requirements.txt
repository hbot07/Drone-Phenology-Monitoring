# =============================================================================
# Drone Phenology Monitoring — combined Python requirements
#
# Derived from the Dockerfile (the authoritative build). This is a single,
# pinned manifest of every Python package used across BOTH runtime
# environments defined in the Dockerfile:
#     dpm-tracking   — FastAPI dashboard + phenology/tracking scripts
#     dpm-detectree  — PyTorch + Detectron2 + Detectree2 crown detection
#
# IMPORTANT — read before `pip install -r`:
#   * The Docker image installs the heavy packages with conda/mamba, not pip:
#       - GDAL and pytorch-cuda come from conda channels and do NOT pip-install
#         cleanly. `pip install GDAL` needs a matching system libgdal-dev, and
#         there is no pip package for `pytorch-cuda` (the CUDA runtime ships
#         with the correct torch build from the PyTorch index).
#   * dpm-tracking and dpm-detectree are SEPARATE conda envs on purpose — their
#     deep dependencies conflict (that is why the Dockerfile keeps them apart).
#     Installing this whole file into ONE environment may not resolve cleanly.
#
#   For a faithful, reproducible build use the Dockerfile. Use this file as a
#   complete dependency inventory, or for a pip-only environment where you
#   accept the caveats above (install system libgdal-dev and the right torch
#   wheel first).
#
# Package-name notes (conda name -> pip name):
#   opencv        -> opencv-python
#   pytorch       -> torch
#   gdal          -> GDAL           (version must match system libgdal)
#   pytorch-cuda  -> (no pip package; use the CUDA torch wheel)
# =============================================================================
